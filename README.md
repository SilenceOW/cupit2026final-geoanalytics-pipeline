# Building-height modelling for Saint Petersburg

A team project for the **MTS geoanalytics case at Changellenge Cup IT 2026**. Our team, DDBuilder, placed **3rd in the final**.

**My role:** Data Scientist / ML Engineer — Andrey Kolesnikov.

The pipeline creates a unified building-height dataset by cleaning geospatial data, matching buildings across sources, predicting missing heights, and validating the output. The repository includes notebooks, supporting scripts, and the solution presentation.

- **Pipeline:** cleaning → building matching → height modelling → validation → visualization.
- **Stack:** Python, geospatial data processing, and XGBoost.
- **[Solution presentation](MTS%20Solution.pdf)**
- **[Companion web visualization](https://github.com/SilenceOW/cupit2026final-geoanalytics-visualization)**
